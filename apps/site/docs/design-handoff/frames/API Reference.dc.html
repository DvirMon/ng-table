1. State Layer

Store API

Every entry point the state layer exposes. One table per surface, same columns throughout.

createTable(options)

Creates a store. All options are optional except data.

Name Type Description
data Signal<T[]> The source rows. Never mutated.
rowKey (row: T) => string Identity for selection. Defaults to reference equality.
initialSort SortState | null Applied before first read.

withSorting()

Adds a comparator-driven sort behavior over the store's rows.

Name Type Description
compare (a, b) => number Per-column comparator. Must be pure.
multi boolean Allow a second sort key. Off by default.
sortDir 'asc' | 'desc' Current direction, as a signal.
⚠
Deprecated in v2
sortBy is replaced by compare. It still works and will be removed in v3.

withSelection()

Stores selection as a set of row keys, so it survives a refetch.

Name Type Description
selected Signal<Set<string>> Selected row keys.
toggle (key: string) => void Adds or removes one key.
mode 'single' | 'multi' Defaults to multi.
