About

Designed for flexibility. Built for Angular.

NGP Table replaces the opinionated data grid with a set of low-level behaviors. State, sorting and selection live in signals; rendering stays entirely yours. No overrides, no theme to fight, no bundle you did not ask for.

Headless by design

Every element is yours to render. The primitive supplies structure, roles and state — never a stylesheet.

Accessible out of the box

Grid semantics, roving focus and full keyboard navigation are built in and tested against screen readers.

Composable behavior

Take sorting without selection, or selection without pagination. Each behavior is an independent directive.

Powered by signals

Row state is reactive by default and zoneless-ready, so updates stay predictable at any row count.

Virtualized when it matters

Opt into windowed rendering for large sets without changing your template or your row markup.

Made for design systems

A stable behavioral contract underneath your tokens, so the table matches the rest of your system.
