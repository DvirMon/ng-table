NGP Table is a headless data table for Angular. You bring the markup and the styles; the table
brings the state: sorting, filtering, grouping, selection, expansion and row editing, all as
signals.

## How the docs are organized

- **Getting Started** — what the table is and how a first table fits together.
- **State Layer** — `createTable()` and the `with*()` features that add behavior to it.
