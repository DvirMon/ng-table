aggregate is a grouping declaration, keyed by declared column id like every other schema concern — not a column option. Here amount carries a sum, so every header at every depth shows one.

A parent total is the sum of its own leaves, not of the headers beneath it — so the Region row equals its categories added up, at every depth and with no blank-at-depth-0 hole.

Aggregates are post-filter by construction, because filter precedes group in the pipeline: a cluster only ever sees rows that survived filtering. grouping-selection composes withFiltering() and has the control that proves it.
