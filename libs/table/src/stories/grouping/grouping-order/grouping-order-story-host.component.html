applyGroupOrder orders group headers among their siblings at one level — not the rows inside a group, which is withSorting(), and not which groups exist, which is when. Pick a comparator in Controls.

A caller-supplied ranking — {{ externalOrder.join(' → ') }} — with values absent from it sorting last. The shape a saved report or a pinned-priority list takes.

} @case ('throwing') {

The comparator throws on every sibling pair it is handed, and the table is still up. Per ADR-0014 the clustering sort catches, falls back to stable first-occurrence order for the affected levels, and reported it once for this evaluation, to the console.
