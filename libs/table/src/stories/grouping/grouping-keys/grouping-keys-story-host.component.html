Two declarators, one lesson: groupKey decides what a level clusters on; an initial entry's label decides what its header calls itself. Every header below shows both, as label: value.

Sales Region carries an explicit initial label — it wins even though a region column exists with its own label ("Region"). Closed has none, so it falls back to the matching closedAt column's own label.

groupKey buckets closedAt into a YYYY-MM string. Twelve distinct timestamps collapse into {{ table.groupIds().length }} group ids. Turn the toggle off in Controls and the engine groups on the exact Date instead — it never coarsens a key on its own (D7).
