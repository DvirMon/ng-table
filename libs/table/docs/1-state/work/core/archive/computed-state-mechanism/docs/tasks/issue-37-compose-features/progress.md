## Step 4, case 40 — standalone-composite row type (input for #44)

The predicted limitation holds. `composeFeatures(withMatchFlag((row) => …))` declared
**standalone** infers `row: unknown` — no contextual `In`, so the feature's `In` falls back to
its `Shape` constraint and `RowOf<Shape>` is `unknown`. The **same call inline** in a
`createTable()` slot infers `row: Invoice`. Both assertions are pinned in case 40.
