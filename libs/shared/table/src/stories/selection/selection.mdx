# Selection

Two stories, because the mode is a construction-time argument rather than a toggle:
`enableMultiRowSelection: false` is passed to `withSelection()` at construction, so a single host
switching between them would carry a dead branch.

Shared: `fixtures/schema.ts` and `selection-story.css`, at the bottom of this page. Both configs
have the same shape — the mode is the `withSelection()` argument, not a config field.

---

## Multi

The whole read/write surface of `withSelection()` on one screen, including a `selectionChanged`
event log — the only place a single-delta clear and a silent reconciliation prune are
distinguishable from each other.
