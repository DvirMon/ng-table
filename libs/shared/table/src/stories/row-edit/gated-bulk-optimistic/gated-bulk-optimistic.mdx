# Gated Edit — Bulk Create, Optimistic Save

Answers D32 (`docs/0-product/row-editing.md` §1.8/OQ-7, `docs/1-state/row-mutations.md`): opening
several new rows uses `createRow`'s array overload — one call, no consumer loop — and saving them
sends one `POST /api/rows/bulk` request instead of N separate ones, so a failure reverts and
reopens the whole batch together. `../gated-multiple-optimistic/`'s Save All is the other, older
answer to the same open question: N independent requests, N independent outcomes.

<Canvas of={GatedBulkOptimisticStories.Default} />

## Forced failure

Every row in the batch reverts to blank and reopens together — not some succeeding while others
fail, which is the contrast with `../gated-multiple-optimistic/`'s Save All (N independent
requests, N independent outcomes).
