# Selection × Filtering

Two features composed, and the place their edges meet. A selected row that a filter moves out of
view stays selected — the opposite of MUI X's documented behaviour, which deselects it — and
clearing the filter brings the selection back unchanged.

One gap is rendered rather than papered over: nothing shipped reports how many selected rows are
currently hidden, so the canvas says so instead of computing a stand-in count in the story host.
The notice disappears on its own when that signal lands.
