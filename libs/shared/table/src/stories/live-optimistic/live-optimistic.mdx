# Live Table + Rollback

The always-editable table with an undo path. Composes `withOptimistic()` and **not**
`withRowEdit()` — there is no button to open a row, so there is no edit session to track. The
focus session *is* the edit session (D39), which is why the same three rollback verbs work here
and in the gated flow.

`table.editing()` stays empty for the whole story. `table.pending()` is the in-flight set.
