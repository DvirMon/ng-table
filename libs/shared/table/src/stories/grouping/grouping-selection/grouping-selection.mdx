# Grouping — Group selection

The `cascade` control is this story's whole argument, not a convenience. D16 made the group-selection
cascade consumer-owned precisely because the three major libraries ship three different defaults, so
a single hardcoded cascade in a story would read as the library taking a position it deliberately
does not take. All three are written here as ordinary code over one `rowsOf()` call.
